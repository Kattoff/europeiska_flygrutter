# Analys av europeiska flygrutter

## Mål

Målet med projektet är att analysera data om europeiska flygrutter med hjälp av Python.

Projektet ska visas hur man kan använda Python för att läsa, analysera och söka i data från en CSV-fil.

## Metod

Jag använde en CSV-fil med information om europeiska flygrutter.

I projektet använde jag:
-csv-biblioteket för att läsa filen
-If-satser och loopar
-egna funktioner
-klasser och arv
-Try/except för felhantering
-Matplotlib för visualisering
-input för att låta användaren söka efter flygrutter 

## Resultat

Programmet kan läsa data från CSV-filen och visa information om olika flygrutter.
Användaren kan skriva in ett anvgångsland och ett ankomstland och få fram matchade flygrutter.
Programmet visar också antal flyg per vecka och en enkel graf med Matplotlib.

## Analys

Resultatet visar att flygfrekvensen varierar mellan olika destinationer.

Projektet visar också hur Python kan användas för att arbeta med verkliga data inom flygbranschen.

Det kan vara relevant för en AI-utvecklare eftersom datahantering, analys och automatisering är viktiga delar inom AI-utveckling.


## Reflektion

Det som gick bra var att läsa in CSV-filen och söka efter flygrutter.

Det som var svårare var att förstå funktioner, visualisering.

Jag lärde mig hur olika delar av Python kan användas tillsammans i ett projekt.

Om jag skulle utveckla projektet vidare skulle jag kunna lägga till fler sökalternativ och fler visualiseringar.
